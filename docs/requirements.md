# 智能竞品分析系统 -需求文档 
## 1.项目背景
    用户在进行竞品分析时，需要花费大量时间搜索和整理不同竞品的信息。
    本项目希望通过 Agent 自动完成竞品信息收集、整理和分析，降低人工进行竞品分析的成本。
## 2.用户 
    主要面向:
    -亚马逊运营
    -市场分析人员
    -创业人员
## 3.用户输入
    用户输入两个竞品
    例如:
    竞品A:Asin :xxxxx
    竞品B:Asin :xxxxx
## 4.系统输出
    生成一份结构型报告，包括:
    1.竞品名称
    2.竞品标题
    3.竞品asin
    4.竞品五点
    5.竞品评级
    6.竞品评论 
    7.价格差异
    7.核心关键词
    8.分析总结
    9.产品差异
## 5.mvp范围
###  MVP 包含
    1.两个竞品名称
    2.agent用户需求
    3.Amazon Product Data Tool
    tool:结构型报告中的内容
    4. Web Search Tool
    5.搜集竞品公开信息
    6.LLM分析竞品信息
    7.生成markdown文档
    8.提供信息来源
### mvp 暂不包含
    1. 用户登录
    2. 权限系统
    3. Web前端
    4. 评论情感分析
    5. 关键词竞争度分析
    6. 自动监控竞品价格
    7. 定时竞品监控
    8. Docker部署
## 核心流程
    用户>Agent>判断需要哪些商品信息>Amazon product Data Tool>
    获取结构化商品数据>LLM分析>竞品分析报告
